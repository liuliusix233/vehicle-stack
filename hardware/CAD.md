## 装配（来自 notes.md）

| 件 | 固定方式 |
| --- | --- |
| 屏板 → 底舱 | M3×10 自攻 ×4（Ø2.8 预孔） |
| 屏板下 → 罩角柱 | M3×12 ×4（Ø2.5×7.5 预孔） |
| 快充模块 | M2×5 自攻 ×4 |
| Pi | 两侧托边 + 扎带 ×2 |

总高：底舱 32 + 屏板 3 + 罩 12 = **47 mm**。

## 打印建议（不是硬性要求）

| 项 | 建议 | 原因 |
| --- | --- | --- |
| 材料 | PETG 或 ASA | 车内夏天暴晒，PLA 会软化 |
| 层高 | 0.2 mm | 强度/时间平衡 |
| 摆放 | 底舱平放贴床；罩竖放 | 减少支撑 |
| 支撑 | 以切片预览为准 | 悬空结构不多 |
| 填充 | 20–30% | 结构件，不需要实心 |

## 注意

- 主体是**修改版**，与 v9 原始底舱外形一致但内部有改动；改尺寸请回 CAD 源文件（不在仓库）。
- 螺丝全部自攻，预孔尺寸见 `notes.md`，打之前先确认孔径。
- 装屏幕前先干装一次，确认驱动板与快充不打架。
