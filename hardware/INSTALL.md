# 安装与走线

> 车上作业，安全第一。动线前断开 12V 负极；涉及保险与高压的部分交给专业店。

## 1. 取电链路（先理清再动手）

**两条独立回路，不要并在一起：**

```
回路 A（主回路）：DJI Power 1000 mini ── 行车闪充线（线内自带保险）──► 汽车电瓶
                    正极 → 电瓶正极桩头；负极 → 电瓶负极桩头；一根线插上即可

回路 B（弱电）：  DJI Power 1000 mini
                   └─ PD 口 ── PD 诱骗线（固定 12V）──► 12V 母线（0.75mm²，无外接保险）
                                                        ├─► 哨兵 DVR（4CH 360）
                                                        └─► 降压 12V→5V 5A ──► Pi
```

- 回路 A 的保险做在线里；回路 B **实际没装保险**（负载 <3A，靠电源自身保护）。
- 回路 B 与汽车电瓶无电气连接，不要接车身搭铁。
- 降压模块放在 12V 母线末端、靠近 Pi，减少线损。
- 所有接头做好固定，避免行车震动松脱。

## 2. 走线：**回路 A 的行车闪充线**（实拍见 `images/sdc-install-route.jpg`）

> 注意：这节讲的是**从后备箱通到机舱电瓶的那根闪充粗线**。
> 给 Pi / DVR 供电的 0.75mm² 细线（回路 B）从后备箱引出，**走脚垫下方到中控台**；不穿底盘、不进机舱。

1. 取下**后备箱储物槽**，露出车架与线束通道。
2. 拆掉车架上的**塑料护板**，露出通往机舱的走线路径。
3. **从机舱穿过底盘**走线，全程套 **AD28.5 波纹管 5 m** 防磨。
4. 穿线孔处理（重点）：
   - 先用**丁基胶带彻底堵死**，压实到无缝隙；
   - 再用**硅橡胶填缝**，等完全固化后再走水测试。
5. 线束每隔 20–30 cm 用扎带固定，远离排气管与运动部件。

## 3. 显示与主机

1. 条屏驱动板 HDMI 口 + Pi 的 mini HDMI 口 → **双头 mini HDMI 软排线**。
2. 软排线走线避免 90° 折弯，弯曲半径 ≥ 10 mm。
3. Pi 固定在后备箱侧面，远离热源；HDMI 与电源线分开走，减少干扰。

## 4. 验收

```bash
# Pi 上
fbset | head -5                      # 期望 240x960（按实际面板）
systemctl status diyhud              # active (running)
curl -s http://127.0.0.1:8080/       # relay/OBD 代理起来了吗
```

- [ ] 通电后条屏正常出画面，无花屏/偏移
- [ ] 熄火后哨兵仍在录（DVR 独立供电）
- [ ] 穿线孔淋水不渗（重点部位）
- [ ] 行驶 20 km 后复查扎带与接头

## 5. 安全

- 任何取电必须经保险，禁止裸接常电。
- 后备箱密闭空间不要放未固定的重物（电源本体要绑牢）。
- 不建议在无人看管时用车辆原电瓶给大功率设备供电。
