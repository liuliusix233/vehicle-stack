# v9（回退 v7 叠层 + 快充靠左顶墙）

## 尺寸
148 × 50 × 32 底舱，屏板 3 → 35；罩 12 → **总高 47**
（v8 的 20mm 单层方案已废，因为它把 USB 挤死了）

## 快充模块定位（48×33，含 5521）
- **左端顶墙**：x −71.6 … −23（槽内 1.2 深，四角 6×2.7 长圆孔容 ±3）
- **5521 DC 座朝 −X 壁**：壁孔 **Ø10.5 @ y=0, z=7**，外侧再铣 15×11.2×1.6 让位凹台，便于插头外壳进入
- **2 个 USB 出线槽**：−Y 侧壁，**12×8 @ z 16–24**，x=−62 与 −42；模块顶部 15.2，槽在它上方
- ⚠ USB 插头必须在**合盖前**插好，线从这两个槽引出；合盖后无法再插拔（净空 16.8，够放线不够伸手）

## 其他件

屏板螺钉柱：x=−30 与 +60，y=±21（避开驱动板与快充）。
Pi 的 HDMI 边在 +46，离 +X 内壁 25.6mm，软线插头够用。
