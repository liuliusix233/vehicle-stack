# 接线示意（两个独立回路，别混）

> 示意图，不是施工图。实际走线交给汽修店。
> **最重要的一点：户外电源到电瓶、户外电源到设备，是两条完全独立的回路。**
> 走底盘、套波纹管、穿钢板的那根是**行车闪充线（回路 A）**；给 Pi 供电的 0.75mm² 细线走**脚垫下方**，从后备箱引到中控台。

## 回路 A：户外电源 ⇄ 汽车电瓶（主回路）

```
  DJI Power 1000 mini
     └─[ DC 输出 ]── 行车闪充线（SDC，线内自带保险）──► 汽车电瓶
                                                        ├─ 正极 → 电瓶正极桩头
                                                        └─ 负极 → 电瓶负极桩头
```

- **就一根线**，插上即可；保险已经做在闪充线里，不需要再外接。
- 作用：行车时给电源充电、停车时给车补电（双向），以及防止电瓶亏电。
- 拆装顺序：**先拆负极、最后接负极**（防打火）。

## 回路 B：户外电源 → 车上设备（弱电）

```
  DJI Power 1000 mini
     └─ PD 口 ──[PD 诱骗线，固定 12V]──► 12V 母线
                                          （0.75mm² 纯铜，5 m，**无外接保险**）
                                            ├─► 4CH DVR 哨兵（12V）
                                            └─► 降压模块 12V→5V 5A ──► Pi Zero 2 W（5V）
```

- 这条回路**与汽车电瓶没有电气连接**，不接车身钣金、也不接电瓶桩头。
- **实际没有装保险**：Pi + DVR 总电流 <3A，靠电源 DC 口自身的过流保护；想加就上 3–5A。
- 降压模块放在 12V 母线末端、靠近 Pi，减少线损。

## 为什么必须分开

| | 回路 A | 回路 B |
| --- | --- | --- |
| 电流 | 大（几十安，取决于闪充功率） | 小（1–3A） |
| 线径 | 闪充线专用线 | 0.75mm² |
| 保险 | 线内自带 | 无（实际未装） |
| 接点 | 电瓶正/负极桩头 | 只在电源与设备之间 |

把 B 并在 A 上，等于用 0.75mm² 的线去跑几十安的电流——**会烧线**。

## 关键点

### 回路 A（行车闪充线，走底盘的那根）

| 项 | 要求 | 原因 |
| --- | --- | --- |
| 用线 | 成套的行车闪充线，**不要自己接** | 线内保险与线径是配套的 |
| 接点 | 正极 → 电瓶正极桩头；负极 → 电瓶负极桩头 | 直连电池，压降最小；不是车身钣金搭铁 |
| 走线 | 后备箱槽 → 拆车架塑料护板 → 机舱底盘 | 实拍见 `hardware/images/sdc-install-route.jpg` |
| 护套 | **AD28.5 波纹管 5 m** 全程套 | 底盘耐磨、防割 |
| 穿孔 | **丁基胶带堵死 + 硅橡胶填缝** | 防水，固化后淋水验证 |
| 拆装 | 先拆负极、最后接负极 | 防打火 |

### 回路 B（0.75mm² 细线，后备箱 → 中控台）

| 项 | 要求 | 原因 |
| --- | --- | --- |
| 走线范围 | **后备箱 → 中控台，走脚垫下方**；不穿底盘、不进机舱 | 只在乘员舱内走，避开底盘与高温区 |
| 保险 | **未装** | 负载 <3A，电源自带过流保护；要装选 3–5A |
| 负极 | 回到电源的 DC 负，不接车身 | 独立回路，接了车身反而形成地环路 |
| 线径 | 0.75 mm² | 1–3A 负载足够；5 m 时压降约 0.4–0.6 V @5A |
| 降压模块 | 放在母线末端、靠近 Pi | 减少线损 |

## PD 诱骗说明

- 电源 PD 口默认协商电压；诱骗线把它固定到 12V。
- 诱骗出来的 12V 只服务弱电设备，不要拿它带大功率负载。
- 图上 997W / 1066W 那种输出走的是电源自带的 AC 插座，不经这条 12V 线。
